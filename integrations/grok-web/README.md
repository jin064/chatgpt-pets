# Pet Studio · Grok 웹 알림 (실험 버전)

Grok 웹 채팅의 응답 중지 버튼이 나타난 뒤 전송 버튼으로 돌아오면 선택한 소리를 재생하는 Chrome 확장입니다.
기본 음성은 우사기의 “우나!”이며 설정 화면에서 다른 파일로 바꿀 수 있습니다.

## 설치

1. Chrome 116 이상에서 `chrome://extensions`를 엽니다.
2. 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 선택합니다.
3. 이 폴더를 선택합니다. ZIP을 받았다면 먼저 압축을 풀고 `manifest.json`이 있는 `pet-studio-grok` 폴더를 선택합니다.
4. 확장의 **세부정보 → 확장 프로그램 옵션**에서 **Grok 웹 연결**을 누르고 `https://grok.com/*` 접근 권한을 확인합니다.
5. **소리 테스트**를 누르고, 이미 열려 있던 Grok 탭을 새로고침합니다.
6. Grok에서 답변 하나를 받아 완료 때 소리가 나는지 확인합니다. 연결 해제는 설정 화면에서 할 수 있습니다.

Chrome이 실행 중이고 Grok 탭이 열려 있어야 합니다. 이 버전은 Chrome 확장이며 iOS·Android 등 별도 Grok 앱에는 적용되지 않습니다.

## 데이터와 권한

- `storage`: 음성 파일(최대 5MB), 알림 켜짐, 최근 완료 시각·재생 오류를 이 브라우저에 보관합니다. Chrome 계정 동기화 저장소는 사용하지 않습니다.
- `offscreen`: 백그라운드에서 소리를 재생합니다.
- `scripting` 및 선택적 `https://grok.com/*` 접근: 허용한 사이트에 완료 감지 코드를 넣습니다. 허용 전에는 사이트 코드를 실행하지 않습니다.
- 대화 본문, 입력한 질문, 계정·쿠키를 읽거나 저장하지 않습니다. 외부 서버로 데이터나 음성을 전송하는 코드와 원격 스크립트가 없습니다.
- 연결 해제는 알림을 끄고 사이트 접근 권한을 반납합니다. 이미 주입된 코드는 다음 새로고침까지 남지만 비활성 상태가 됩니다.
- 웹 버튼의 접근성 이름·테스트 ID와 표시 상태만 확인합니다. 오류 알림이 있거나 사용자가 중지·이동한 경우 소리를 억제합니다.

## 검증과 한계

2026-10-23: 완료 상태 추적, 일시적 버튼 변화, 중지, 페이지 이동, 오류, 권한 없는 메시지, 재생 실패의 자동 테스트를 통과했습니다.
**실제 Chrome 설치 및 로그인한 Grok 채팅의 완료 재생은 아직 검증하지 않았습니다.**
공개 Grok 홈페이지에서 전송 버튼의 `data-testid="chat-submit"`을 확인했습니다. 응답 중지 버튼의 언어별 이름·ID는 실제 채팅에서 추가 확인이 필요합니다.
Grok의 화면·언어·모드가 바뀌면 누락이나 오탐이 생길 수 있습니다. 매우 짧은 응답, 탭 정지·절전·네트워크 오류도 감지에 영향을 줍니다.
설정의 “최근 감지·재생”은 이 감지기가 재생을 시작한 시각이며, 답변의 성공을 보증하는 서버 이벤트가 아닙니다.

테스트:

```sh
node --test integrations/grok-web/tests/*.test.cjs
```

구현에 사용한 공식 문서: [선택적 권한](https://developer.chrome.com/docs/extensions/develop/concepts/declare-permissions), [콘텐츠 스크립트](https://developer.chrome.com/docs/extensions/reference/api/scripting), [백그라운드 음성](https://developer.chrome.com/docs/extensions/reference/api/offscreen).
